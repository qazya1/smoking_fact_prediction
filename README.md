# Smoking Prediction — прогнозирование статуса курения по биомедицинским показателям

**End-to-end ML-проект:** исследование медицинских данных → подготовка признаков → обучение нейронной сети → REST API с веб-интерфейсом → развёртывание в Docker.

Сервис принимает показатели медицинского осмотра и оценивает вероятность того, что человек курит. Проект демонстрирует не только обучение модели на табличных данных, но и её интеграцию в приложение с валидацией запросов и воспроизводимым развёртыванием. **Это учебный прототип, а не медицинский диагностический инструмент.**

## Результаты

| Метрика | Значение на валидационной выборке |
| --- | ---: |
| Accuracy | **0,7609** |
| ROC-AUC | **0,8443** |
| Precision | **0,6597** |
| Recall | **0,7147** |

Значения приведены по последней эпохе обучения на графиках TensorBoard из отчёта. Использовалось стратифицированное разделение **75% / 25%**; результаты на отдельной независимой тестовой выборке в отчёте не представлены. Метрики не следует интерпретировать как подтверждённую клиническую точность.

## Данные и постановка задачи

Источник — [Body Signal of Smoking (Kaggle)](https://www.kaggle.com/datasets/kukuroo3/body-signal-of-smoking): **55 692** записи медицинских осмотров жителей Южной Кореи, **27** исходных столбцов, без пропусков. Цель — бинарная классификация `smoking`: `1` — курит, `0` — не курит. Доли классов: **36,7% / 63,3%** соответственно.

В модель поступают биомедицинские признаки: возраст и антропометрия, острота зрения, артериальное давление, глюкоза, липидные показатели, гемоглобин, печёночные ферменты и стоматологические показатели. Подробнее — [описание данных](docs/dataset.md).

## Что реализовано

### 1. Анализ и предобработка

- Исследование распределений и корреляций; исключение технических, константных и слабо связанных с целевой переменной признаков.
- Обработка экстремальных значений по заданным порогам для остроты зрения, давления, глюкозы, ЛПВП и АЛТ; по отчёту суммарно исключено **менее 2%** наблюдений.
- Логарифмическое преобразование скошенных распределений, `RobustScaler` и `StandardScaler`; бинарное кодирование категориальных значений.
- Сохранение предобработки вместе с моделью, чтобы применять одинаковые преобразования при обучении и инференсе.

### 2. Нейронная сеть

Полносвязная модель **MLP** с четырьмя скрытыми слоями `128 → 64 → 32 → 16`, активациями `ReLU` и выходом `Sigmoid`. Для регуляризации использованы `Dropout` и `BatchNormalization`. Обучение: `TensorFlow / Keras`, оптимизатор `Adam` (`learning_rate=0.001`), `batch_size=128`, **Binary Focal Cross-Entropy** для работы с дисбалансом классов. Метрики и динамика обучения отслеживались через `TensorBoard`. Подробнее — [архитектура и обучение](docs/model.md).

### 3. API и веб-интерфейс

`FastAPI` предоставляет два маршрута:

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| `GET` | `/` | HTML-форма ввода показателей |
| `POST` | `/send-data` | JSON-запрос с показателями → предсказание |

Веб-форма отправляет данные через Fetch API без перезагрузки страницы. `Pydantic` проверяет обязательные поля, типы и допустимые диапазоны; дополнительная проверка защищает от пустого результата предобработки. Обученный пайплайн загружается **один раз при старте приложения** и переиспользуется между запросами.

Пример успешного ответа:

```json
{
  "smoking": true,
  "probability": 0.8741,
  "label": "Курит"
}
```

`probability` — выход модели для класса «курит», а не медицински подтверждённая индивидуальная вероятность. Описание полей, примеры запросов и коды ошибок — в [документации API](docs/api.md).

### 4. Контейнеризация и проверки

Приложение упаковано в `Docker` на базе `python:3.11-slim`; настроены `HEALTHCHECK` и запуск `uvicorn` с одним worker. В отчёте описаны функциональные проверки успешных запросов и ошибок валидации (`HTTP 422`), а также проверки на двух составленных тестовых профилях. Такие проверки демонстрируют работу сервиса, но не заменяют независимую оценку модели.

## Быстрый запуск

Понадобятся Python и зависимости из `requirements.txt` либо установленный Docker.

**Локально:**

```bash
pip install -r requirements.txt
uvicorn main:app --reload
```

**В Docker:**

```bash
docker build -t smoking-predictor .
docker run -p 8000:8000 smoking-predictor
```

Откройте `http://localhost:8000/` для формы; интерактивная документация FastAPI доступна по `http://localhost:8000/docs`.
