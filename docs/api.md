# API

REST-сервис на **FastAPI**, разворачивается в Docker-контейнере. При старте
пайплайн (`SmokingNNPipeline`) загружается один раз через `lifespan`-менеджер
и переиспользуется для всех последующих запросов.

## Валидация входных данных

Валидация происходит в два слоя:

1. **Pydantic-схема** (`SmokingInput`) — проверяет типы, обязательность полей
   и числовые диапазоны. Границы полей точно соответствуют порогам отсечения
   выбросов, использованным при обучении (см. [dataset.md](dataset.md#клиническое-обоснование-отсечения-выбросов)),
   чтобы модель не получала значения вне области, на которой она обучалась.
   Нарушение → **HTTP 422**, до вызова пайплайна.
2. **Защитная проверка пайплайна** — если после внутренней предобработки
   (`_transform_features`) строка была отфильтрована и DataFrame оказался
   пустым → **HTTP 400**.

## `GET /`

Возвращает HTML-страницу с интерактивной формой ввода показателей.
Форма отправляет данные через Fetch API на `POST /send-data` без перезагрузки
страницы.

| Параметр | Значение |
|---|---|
| Метод | GET |
| URL | `/` |
| Content-Type | `text/html; charset=utf-8` |
| Код успеха | 200 OK |
| Тело ответа | HTML-документ (`templates/index.html`) |

## `POST /send-data`

Принимает JSON с биомедицинскими показателями, выполняет предобработку и
возвращает предсказание модели.

### Тело запроса

`Content-Type: application/json`

| Поле | Тип | Ограничение | Описание |
|---|---|---|---|
| gender | string | `"M"` или `"F"` | Пол |
| age | float | > 0 | Возраст, лет |
| height_cm | float | > 0 | Рост, см |
| weight_kg | float | > 0 | Вес, кг |
| waist_cm | float | > 0 | Объём талии, см |
| eyesight_left | float | 0 – 2 | Острота зрения, левый глаз |
| eyesight_right | float | 0 – 2 | Острота зрения, правый глаз |
| systolic | float | > 0, ≤ 180 | Систолическое АД, мм рт. ст. |
| relaxation | float | > 0, ≤ 120 | Диастолическое АД, мм рт. ст. |
| fasting_blood_sugar | float | > 0, ≤ 350 | Глюкоза натощак, мг/дл |
| triglyceride | float | > 0 | Триглицериды, мг/дл |
| HDL | float | > 0, ≤ 300 | ЛПВП-холестерин, мг/дл |
| hemoglobin | float | > 0 | Гемоглобин, г/дл |
| ALT | float | > 0, ≤ 100 | АЛТ, МЕ/л |
| Gtp | float | > 0 | ГГТ, МЕ/л |
| tartar | string | `"Y"` или `"N"` | Зубной камень |
| dental_caries | string | `"Y"` или `"N"` | Кариес |

### Коды ответов

| Код | Статус | Описание |
|---|---|---|
| 200 | OK | Предсказание выполнено успешно |
| 400 | Bad Request | Пайплайн отфильтровал запись (граничный случай) |
| 422 | Unprocessable Entity | Нарушение типов или диапазонов Pydantic |
| 500 | Internal Server Error | Непредвиденная ошибка внутри пайплайна |

### Тело успешного ответа (200)

| Поле | Тип | Описание |
|---|---|---|
| smoking | boolean | `true` — курит, `false` — не курит |
| probability | float | Вероятность класса 1, диапазон `[0.0, 1.0]` |
| label | string | `"Курит"` или `"Не курит"` |

### Пример

Запрос (профиль вероятного курильщика):

```json
{
  "gender": "M", "age": 42, "height_cm": 175, "weight_kg": 84, "waist_cm": 94,
  "eyesight_left": 1.0, "eyesight_right": 1.0,
  "systolic": 138, "relaxation": 88,
  "fasting_blood_sugar": 108, "triglyceride": 215, "HDL": 36,
  "hemoglobin": 17.2, "ALT": 44, "Gtp": 92,
  "tartar": "Y", "dental_caries": "Y"
}
```

Ответ:

```json
{ "smoking": true, "probability": 0.8741, "label": "Курит" }
```

При ошибках (400/422) тело содержит поле `detail` с описанием нарушенных
ограничений.

## Тестирование

### Функциональные тесты

- `GET /` — HTTP 200, `Content-Type: text/html`;
- `POST /send-data` с полным корректным запросом — HTTP 200 с предсказанием;
- `POST /send-data` с `systolic = 210` — HTTP 422 (нарушение `le=180`);
- `POST /send-data` без поля `dental_caries` — HTTP 422 (обязательное поле);
- `POST /send-data` с `dental_caries = "X"` — HTTP 422 (нарушение `Literal["Y","N"]`).

### Семантические тесты

Проверка содержательности предсказаний на клинически правдоподобных профилях:

| Показатель | Профиль A (курильщик) | Профиль B (некурящий) |
|---|---|---|
| Пол / возраст | М, 42 года | Ж, 34 года |
| Рост / вес / талия | 175 см / 84 кг / 94 см | 163 см / 57 кг / 73 см |
| Систол./диаст. АД | 138 / 88 мм рт. ст. | 112 / 72 мм рт. ст. |
| Глюкоза натощак | 108 мг/дл | 84 мг/дл |
| Триглицериды | 215 мг/дл | 88 мг/дл |
| ЛПВП | 36 мг/дл (снижен) | 71 мг/дл (норма) |
| Гемоглобин | 17,2 г/дл (повышен) | 13,1 г/дл (норма) |
| АЛТ / ГГТ | 44 / 92 МЕ/л | 17 / 16 МЕ/л |
| Зубной камень/кариес | Y / Y | N / N |
| Ожидаемый результат | `smoking = true` | `smoking = false` |

Профиль A сочетает признаки, типичные для курильщика: сниженный ЛПВП,
повышенные триглицериды и ГГТ, высокий гемоглобин, зубной камень и кариес.
Профиль B соответствует нормативным значениям у некурящего.

## Контейнеризация

- Базовый образ — `python:3.11-slim`;
- `uvicorn` запускается с `--workers 1`: TensorFlow хранит сессию в памяти
  одного процесса и не является fork-safe;
- `HEALTHCHECK` со `--start-period=60s` — загрузка модели при старте занимает
  несколько секунд;
- зависимости копируются отдельным слоем перед исходным кодом для кэширования
  слоёв Docker.
