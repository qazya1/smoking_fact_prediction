# Модель

## Архитектура

Полносвязная нейронная сеть (MLP) — тип архитектуры, традиционно показывающий
конкурентное качество на табличных данных.

| № | Слой | Параметры | Назначение |
|---|---|---|---|
| 0 | Input | 16 признаков | Входной слой |
| 1 | Dense | 128 нейронов, ReLU, He-инициализация | Первичные признаки |
| 2 | Dropout | p = 0,4 | Регуляризация |
| 3 | Dense | 64 нейрона, ReLU, He | Сжатие признаков |
| 4 | Dropout | p = 0,3 | Регуляризация |
| 5 | Dense | 32 нейрона, ReLU, He | Абстрактные признаки |
| 6 | BatchNorm | — | Нормализация активаций |
| 7 | Dropout | p = 0,2 | Регуляризация |
| 8 | Dense | 16 нейронов, ReLU, He | Финальное сжатие |
| 9 | Dropout | p = 0,2 | Регуляризация |
| 10 | Dense (выход) | 1 нейрон, sigmoid | P(smoking = 1 \| x) |

ReLU выбран для всех скрытых слоёв как вычислительно эффективный и не
подверженный затуханию градиента. He-инициализация подобрана специально под
ReLU: дисперсия весов масштабируется пропорционально `2 / fan_in`, что
стабилизирует разброс активаций на старте обучения.

## Регуляризация

Основной метод — **Dropout** на каждом Dense-слое (эффективно снижает
ко-адаптацию нейронов). L2-регуляризация в экспериментах не дала значимого
улучшения — веса и без неё оставались небольшими.

Один слой **BatchNormalization** размещён между третьим и четвёртым
Dense-слоями: стабилизирует обучение и дополнительно ограничивает
переобучение. Добавление других BatchNorm-слоёв улучшения не дало.

## Функция потерь

**Binary Focal Cross-Entropy** (Lin et al., 2017 [2]) — предложена для задач с
дисбалансом классов:

```
FL(pₜ) = −αₜ (1 − pₜ)^γ · log(pₜ)
```

где `pₜ` — вероятность правильного класса, `γ > 0` — параметр фокусировки,
`α` — весовой коэффициент. При `γ = 0` функция совпадает со стандартной
кросс-энтропией; при `γ > 0` легко классифицируемые примеры получают
пониженный вес, и обучение концентрируется на трудных объектах. Дисбаланс
классов 1,72 : 1 в датасете делает применение фокальной функции потерь
обоснованным.

## Метрики

| Метрика | Формула | Интерпретация |
|---|---|---|
| Accuracy | `(TP + TN) / (TP + TN + FP + FN)` | Доля верных предсказаний. Baseline «всегда 0» даёт ≈ 0,633 |
| Precision | `TP / (TP + FP)` | Доля реальных курильщиков среди предсказанных курильщиками |
| Recall (TPR) | `TP / (TP + FN)` | Доля обнаруженных курильщиков среди всех курильщиков |
| ROC-AUC | площадь под ROC-кривой (TPR vs FPR) | `P(score(positive) > score(negative))`; 0,5 — случайный классификатор, 1,0 — идеальный |

Precision и Recall находятся в компромиссе, регулируемом порогом
классификации (Precision–Recall trade-off). В медицинском контексте пропуск
курильщика (FN) обычно обходится дороже ложной тревоги (FP), поэтому Recall
отслеживается наравне с Precision.

## Обучение

- **Оптимизатор:** Adam, learning rate = 0.001;
- **Размер батча:** 128;
- **Разбиение данных:** 75 % train / 25 % validation, стратифицированное по
  целевой переменной;
- **Порог классификации:** 0.5;
- **EarlyStopping** по `val_auc` (patience = 25, восстановление лучших весов);
- **ReduceLROnPlateau** по `val_loss` (factor = 0.5, patience = 10, min_lr = 1e-6);
- **TensorBoard** — логирование метрик и гистограмм весов в ходе обучения.

Реализация — класс `SmokingNNPipeline` в [`smoking_pipeline.py`](../smoking_pipeline.py):
инкапсулирует предобработку, обучение, сохранение/загрузку и инференс в одном
объекте, сериализуемом через `save()`/`load()` (модель — `model.keras`,
параметры препроцессинга — `preprocessing.joblib`, конфиг — `config.json`).
