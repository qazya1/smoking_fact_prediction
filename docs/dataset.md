# Датасет

## Источник

Использован открытый набор данных **Body Signal of Smoking** с платформы Kaggle
(автор: kukuroo3) [6]. Датасет содержит результаты стандартных медицинских
осмотров жителей Южной Кореи: **55 692 записи**, **27 признаков**, пропущенные
значения отсутствуют.

## Целевая переменная

`smoking` уже представлена в числовом бинарном виде (1 — курит, 0 — не курит).

| Класс         | Количество | Доля, % |
|---------------|-----------:|--------:|
| 0 — Некурящий |     35 237 |    63,3 |
| 1 — Курящий   |     20 455 |    36,7 |
| **Итого**     | **55 692** | **100** |

Соотношение классов — приблизительно **1,72 : 1** в пользу некурящих. Дисбаланс
учтён при выборе функции потерь (см. [model.md](model.md#функция-потерь)).

## Удаление неинформативных признаков

Признак исключался, если модуль его корреляции с целевой переменной по
корреляционной матрице был ниже 0,1:

- **oral** — константа (`Y` для всех 55 692 наблюдений), нулевая дисперсия;
- **ID** — технический идентификатор записи;
- **hearing(left)**, **hearing(right)** — слабая корреляция с целевой переменной;
- **Cholesterol**, **LDL** — несмотря на клиническую связь с курением, в данном
  датасете эффект опосредован и маскируется индивидуальной изменчивостью (сильная
  корреляция с полом, возрастом, гемоглобином);
- **Urine protein** — порядковый признак с минимальной дискриминирующей силой;
- **AST** — уступает по корреляции печёночному маркеру АЛТ, с которым сильно
  коррелирует; включение обоих признаков не улучшало качество модели.

## Клиническое обоснование отсечения выбросов

Наблюдения со значениями за пределами клинически допустимых диапазонов —
как правило, технические ошибки измерения или случаи тяжёлой острой патологии,
нетипичные для основной популяции. Их включение в обучение ухудшает
обобщающую способность модели. Суммарно по всем критериям удалено **менее 2 %**
наблюдений.

| Показатель | Порог отсечения | Клиническое обоснование | Доля выбросов |
|---|---|---|---|
| Острота зрения | > 2,0 | Артефакт ввода данных (норма — до 2,0) | 0,17 % (92 записи) |
| Систолическое АД | > 180 мм рт. ст. | АГ 3-й степени, требует медикаментозной терапии [3] | 0,11 % (60 записей) |
| Диастолическое АД | > 120 мм рт. ст. | АГ 3-й степени [3] | 0,06 % (34 записи) |
| Глюкоза натощак | > 350 мг/дл | Тяжёлая гипергликемия, риск гиперосмолярных состояний [5] | 0,03 % (16 записей) |
| ЛПВП-холестерин | > 300 мг/дл | Аналитический артефакт [5] | 2 записи |
| АЛТ | > 100 МЕ/л | Активное воспаление/токсическое поражение печени (>2× верхней границы нормы) [5] | 1,31 % (732 записи) |

После обрезки острота зрения дополнительно центрируется вычитанием 1 (норма → 0).

## Масштабирование признаков

Использовались две стратегии:

**RobustScaler** — устойчив к выбросам, вычитает медиану и делит на межквартильный
размах:

```
x' = (x − Q₂) / (Q₃ − Q₁)
```

Применён к признакам со скошенным распределением: `age`, `weight(kg)`
(предварительно логарифмированы), `height(cm)`, `waist(cm)`,
`fasting blood sugar` (log), `triglyceride` (log), `HDL`, `hemoglobin`, `ALT`,
`Gtp` (log).

**StandardScaler** — центрирование и нормировка по выборочной дисперсии:

```
x' = (x − μ) / σ
```

Применён к показателям артериального давления, распределение которых после
отсечения выбросов близко к нормальному.

Для сильно скошенных признаков перед масштабированием применялось
логарифмическое преобразование `log(1 + x)` — оно приближает распределение к
нормальному и улучшает сходимость градиентного спуска.

## Кодирование категориальных признаков

- `gender` (M/F) → бинарно: M = 1, F = 0;
- `tartar` (Y/N) → бинарно: Y = 1, N = 0;
- `dental caries` уже был числовым бинарным (0/1) и не требовал преобразований.
